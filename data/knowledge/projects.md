# Projects

## Automated Database Code Audit Tool

Built with Python, database schema analysis, security and compliance techniques. It automates schema and query analysis to find vulnerabilities and optimise performance. Available at github.com/waki44/Autonomous-code-autitor

## GymPro Gym Management System

Built with React.js, FastAPI, MongoDB, Tailwind CSS, and Recharts. Features include member registration, membership records, fee tracking, expiry alerts, dashboard analytics, workout filters, and monthly revenue charts. Demo: workout-fee-manager.preview.emergentagent.com

## DataNest AI Assistant

Built with Python, CustomTkinter, and the Google Gemini API. A Windows desktop AI operator with a custom GUI. Available at github.com/waki44/DataNest-AI-Assistant

## AI Content Detector

Built with HTML, CSS, JavaScript, the Claude API, and the Hugging Face Inference API. It provides text and image analysis with confidence scores and explanations. (The GitHub repository was deleted by the owner and is no longer available.)

## Image Caption Generator

Built with Python, PyTorch, Hugging Face Transformers, Salesforce BLIP, and Gradio. It uses BLIP for image captioning with a Gradio UI.

## RumiCloud Share Space

A full-stack cloud storage project built with Lovable AI. Features include uploads, shareable links, and file management. Demo: preview--rumicloud-share-space.lovable.app

## RAG Portfolio Agent & LLM Utilities

Built with Python, vector databases, semantic search, LLM APIs, and REST APIs. Includes a conversational portfolio agent with semantic retrieval and RAG, a local multi-model API wrapper and testing environment, and utilities for file organisation, web scraping, and data processing.

## AI Sentiment Analyzer

Built with Python, Scikit-Learn, TF-IDF, and Streamlit. An end-to-end ML web app that classifies customer reviews into positive or negative sentiments. Available at github.com/waki44/ai-sentiment-analyzer

## FBR Wala — Tax & Wealth Statement CLI

Built in Python. A Pakistan FBR tax calculation and wealth statement CLI engine for salaried individuals and freelancers, designed as an IRIS helper. Available at github.com/waki44/fbr-wala
